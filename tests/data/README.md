# Upstream Test Data

Verbatim copies of the `input`, `output`, and `outhex` test files from
[cyberphone/json-canonicalization](https://github.com/cyberphone/json-canonicalization/tree/32a48195b9b20fe67b1795e39e4509f14d860b45/testdata)
at commit `32a48195b9b20fe67b1795e39e4509f14d860b45`, licensed under the Apache License 2.0.

The files are byte-exact fixtures: `output` files have no trailing newline. They are excluded from
the formatting hooks and from git line ending conversion.
